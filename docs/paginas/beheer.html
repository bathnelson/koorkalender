Agendalink voor leden (abonnement)

Met deze geheime link kunnen leden de planning als abonnement in hun eigen agenda zetten. Repetities in vakanties staan er niet in. Deel de link alleen met leden; wie hem heeft, kan de planning zien. Maak een nieuwe link als hij op de verkeerde plek terecht is gekomen; de oude werkt dan niet meer.

Abonneer in Agenda (iPhone/Mac) Abonneer in Google Agenda Test: bekijk het bestand

Ledenlink (afgeschermde kalender)

De afscherming staat uit: iedereen met het adres kan de kalender zien. Zet een ledencode in config.php op de server om hem af te schermen.

Zet deze link achter het icoontje op de ledensite. Wie via deze link komt, ziet de kalender meteen; de telefoon onthoudt dat. Wie zonder link komt, moet de ledencode uit config.php intypen. Maak een nieuwe link als hij uitgelekt is; leden die via de oude link binnenkwamen, moeten dan opnieuw via de nieuwe link of de code.
